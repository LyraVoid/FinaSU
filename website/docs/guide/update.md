# 更新 FinaSU

## 管理器更新

管理器可以检查应用更新与模块更新。安装与当前内核签名匹配的官方构建；不同签名的管理器可能被内核拒绝。

## 更新内核驱动

已有 Root 时，打开 [安装方式](/guide/install/) 使用“直接安装”，开启刷写前备份，然后重启。不要只替换应用 APK 就认为内核驱动已经更新。

## Android 系统 OTA

OTA 会替换启动分区，从而移除已修补的 FinaSU。

- **A/B 设备**：完成 OTA 后先不要重启，直接选择“安装到未使用的槽位”，再重启进入新系统。
- **非 A/B 设备**：先恢复原厂镜像完成 OTA，再重新修补当前启动镜像。

模块与大部分设置位于 `/data`，系统更新通常不会删除它们，但系统变更可能使旧模块失效。

## 检查版本

在管理器首页和关于页面分别确认管理器版本、内核版本与驱动运行方式。反馈问题时一并提供这些信息。
