# 常见问题

## FinaSU 能做什么

FinaSU 基于内核裁决 Root。它提供内核级 `su` 与白名单、Folk Mount 模块注入、App Profile、FolkZygisk、Sui、SUSFS 能力接口、NoMount、`.fpt` 主题和模块仓库。

## 1. 需要解锁 Bootloader 吗？

需要。FinaSU 要么修补启动镜像，要么在系统启动过程中加载内核模块；锁定的 Bootloader 会拒绝这些改动。解锁通常会清空设备并影响硬件认证。

## 2. FinaSU、KernelSU 和 Magisk 是什么关系？

FinaSU 是 KernelSU 的后继分支，保留内核内白名单模型，并加入新的管理器与内置引擎。Magisk 主要工作在用户态并修补 ramdisk，两者的模块系统不应同时接管启动链。

## 3. 我的设备支持 FinaSU 吗？

需要 arm64 Android 设备。GKI 5.10 或更高推荐使用运行时 LKM；4.14 及以上通常需要自行编译内核。低于 4.14 或没有 GKI 的设备，需要对目标内核移植钩子。

## 4. 怎么安装，会修补哪个分区？

管理器提供选择文件、下载文件、直接安装和 A/B 未激活槽位等方式。修补目标通常是 `boot`；Android 13 及以后拆分 ramdisk 的设备可能是 `init_boot`，以管理器识别结果为准。

## 5. 修补或刷入后无法开机

刷回与系统版本匹配的原厂启动镜像。若没有备份，从同版本固件包提取。分区错误、KMI 不匹配和安全补丁级别不一致都是常见原因。

## 6. 安装了模块却没有生效

检查 Folk Mount 是否被设为“关闭挂载”。模块通常要重启后才生效，也请确认模块自身依赖的 Zygisk、Sui 或配置应用已经就绪。

## 7. 安装模块后无法正常开机

出现首次开机画面后快速按三次音量下键，禁用所有模块后启动。仍然失败时恢复原厂镜像，并把启动阶段日志交给模块作者。

## 8. 什么是元模块，我需要安装吗？

元模块接管普通模块的挂载或安装流程，同时只能启用一个。FinaSU 的内置 Folk Mount 已能处理普通模块；需要特定挂载实现时才安装元模块。

## 9. Folk Mount 和 NoMount 有什么区别？

Folk Mount 是选择挂载提供者并注入模块的引擎；NoMount 通过内核 VFS 路径重定向注入文件，不建立传统挂载。NoMount 随 `ksud` 发布并按 KMI 匹配。

## 10. 什么是 FolkZygisk？还需要别装提供者吗？

FolkZygisk 是内置 Zygisk 引擎。启用并重启即可运行 Zygisk 模块；检测到外部提供者时，内置引擎会让位。

## 11. FinaSU 支持 Xposed 吗？

支持。在可用的 Zygisk 提供者上安装 LSPosed 等现代 Xposed 衍生框架即可。内置 FolkZygisk 与外部提供者只需保留一个活动实现。

## 12. 什么是 Sui？还需要 Shizuku 吗？

Sui 是内置的 Shizuku API 后端，因此兼容应用不需要另外安装 Shizuku。应用权限、默认策略、隐藏名单和诊断由 FinaSU 管理器管理。

## 13. 为什么找不到 SUSFS 设置？

SUSFS 是内核侧能力。FinaSU 只对接已经集成 SUSFS 的目标内核；当前内核未报告支持时，相关页面和开关不会出现。

## 14. 已经授予 Root，应用仍提示没有 Root

检查该应用的 Root Profile、SELinux 域和“卸载模块”策略。授权后强制停止并重新打开应用，确认它确实重新发起了检测。

## 15. 为什么 Root 授权请求没有出现？

应用可能已经在白名单或被拒绝列表中，管理器的授权界面也可能被系统回收。打开“超级用户”页面查找记录，再调整授权。

## 16. 系统更新之后 Root 消失了

OTA 替换了启动镜像。A/B 设备应在重启前安装到未使用的槽位；其他设备需重新修补启动分区。`/data` 中的配置通常仍在。

## 17. 重新安装管理器后为什么认证失败？

内核按 APK 签名识别管理器。debug、自行编译或使用其他密钥签名的构建不会被自动信任。可安装官方构建，或在明确了解风险时将其设为动态管理器。

## 18. 怎么隐藏 Root？

按应用组合策略：先用 App Profile 卸载模块，必要时使用 NoMount，再依据内核能力启用 SELinux 隐藏和 AVC 日志处理。不存在对所有检测都有效的单一开关。

## 19. 如何卸载 FinaSU？

设置中的卸载入口提供临时卸载、永久卸载和恢复原厂镜像。恢复原厂镜像需要匹配的备份；没有备份时用 `fastboot` 刷回固件包中的启动分区。

## 20. 反馈问题时应提供什么？

提供管理器与内核版本、设备型号、Android 版本、完整 KMI、安装方式、复现步骤以及导出日志。说明预期结果与实际结果，避免只发送单张截图。
