# 语言

<Badge text="20 个选项" type="tip" /> <Badge text="即时切换" type="warning" />

“应用语言”选择 FinaSU 管理器界面使用的语言。切换采用热更新：选择后立即重建当前界面并加载语言资源，不需要退出管理器，更不需要重启设备。

::: info 只改管理器界面

语言设置不会修改 Android 系统语言、模块脚本环境、内核日志或第三方应用自己的语言。`ksud` 命令和模块输出也不会因为切换界面语言而翻译。

:::

## 切换方式

:::: steps

1. 进入“设置 → 通用 → 语言”。
2. 点选需要的语言。
3. 当前界面会重建并立即显示新语言。
4. 想恢复系统选择时，点“跟随系统”。

::::

切换过程中可能出现一次短暂的界面重建，这是正常现象。不要在重建期间连续点选多个语言。

## 自定义语言变体

列表后半部分包含项目提供的特殊中文变体：

- **猫娘**：`zh-AG`
- **天道仙文**：`zh-WC`
- **魔法少女**：`mgl`
- **天使语**：`zh-AT`
- **饭庄通语**：`zh-CK`
- **方块世界**：`zh-MC`

它们与其他语言使用同一套即时切换机制，只改变管理器界面文本。

## 注意事项

- “跟随系统”不是某一种固定语言，而是取消管理器的语言覆盖。
- 中文分为简体、繁体及多个风格变体，它们是独立选项。
- 主题包可以保存应用语言字段；导入主题后，语言选择可能随主题一起改变。
- 本文档站点仍以简体中文编写，文档语言不会随管理器内的语言选择自动切换。
