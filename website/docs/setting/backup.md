# 备份

备份设置决定写入目标、内容和恢复入口。

## 目标

- **本地目录**：保存到 `Download/FinaSU`；可直接打开所在目录。
- **WebDAV**：填写服务器、用户名、密码和远程路径，并通过“测试连接”确认可写。

WebDAV 密码必须以可逆形式保存给网络请求，管理器通过秘密存储管理。服务器地址错误或证书不可信时，不应绕过 TLS 校验。

## 内容

- **刷写前备份**：在安装或刷写前保存快照。
- **模块**：归档所选安装包对应模块。
- **超级用户列表**：保存授权应用与策略。
- **分区**：备份管理器检测到的启动分区。

### 立即备份

“立即备份”运行一次当前配置的备份；“管理备份”查看历史和恢复入口。

## 恢复

恢复分区会直接写入设备，必须确认来源、设备、槽位和系统版本。恢复管理数据时应避免同时打开多个管理器实例写入相同文件。

WebDAV 浏览页可以查看、预览、删除远程条目。远程文件不是本地副本，删除后不能从回收站恢复。
