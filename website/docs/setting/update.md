# 更新与版本

## 检查更新

“检查更新”控制管理器在启动后检查新版本。发现更新后仍应确认签名和来源，再安装官方构建。

## 检查模块更新

“检查模块更新”让管理器根据模块仓库元数据检查已启用模块的新版本。停用模块、仓库版本号不完整或作者未提供可靠版本时，可能不会提示更新。

## 更新不是同一件事

- 管理器 APK 更新只替换应用界面与随包资源。
- 内核驱动更新需要重新修补或刷写启动分区。
- `ksud`、内置引擎和 APK 通常随完整的官方构建发布。

只看到管理器版本变化时，不要假设内核驱动也同步更新。完整发布流程见 [更新 FinaSU](/guide/update/)。
