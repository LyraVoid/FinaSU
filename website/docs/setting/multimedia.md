# 多媒体

## 震动

调整界面触感反馈的强度。系统触感策略和硬件能力可能限制实际效果。

## 背景音乐

选择音乐文件后可启用播放、自动播放与循环。音乐由管理器前台界面播放；离开应用或系统回收进程时会停止。

## 音效

- **启动音效**：管理器启动时播放。
- **界面音效**：为点击等交互播放声音。
- **来源**：使用预设或自定义文件。
- **预设 / 作用域**：选择声音与作用范围。
- **选择文件 / 清除文件**：管理自定义音频。

音效只属于外观体验，不影响 Root、模块或授权行为。音量应遵循系统音量与勿扰模式。
