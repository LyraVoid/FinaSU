# 多媒体

<Badge text="设置入口 7/8" type="info" /> <Badge text="只影响管理器" type="tip" />

“多媒体”控制管理器的触摸反馈、背景音乐、触摸音效和启动音效。它们不会改变 Root、模块、授权或 SELinux。

::: tip 进入方式

打开管理器 → 设置 → 点第二行第四个 **多媒体**。

:::

## 功能一览

::: table 四种反馈

| 功能 | 何时出现 | 可以自定义 |
| --- | --- | --- |
| **触摸振动** | 用户在界面中触摸或操作控件时 | 反馈范围、强度 |
| **背景音乐** | 进入并播放管理器背景音频时 | 文件、自动播放、循环、音量、进度 |
| **触摸音效** | 用户触摸界面控件时 | 本地文件或预置音效、反馈范围 |
| **启动音效** | 管理器启动并播放启动反馈时 | 本地文件或预置音效 |

:::

## 触摸振动

触摸振动提供界面触感反馈，与 Root 授权是否成功无关。

开启后可以设置：

- **反馈范围：所有触摸**：所有使用管理器触感反馈的交互都可能触发。
- **反馈范围：导航控件**：主要限于底部、侧边或悬浮导航。
- **强度**：滑块为 `0%–100%`，数值越高通常振动越强。

实际效果仍受设备振动硬件、系统触感策略和省电设置限制。强度为 100% 也不代表所有设备都能产生同样幅度。

::: tip 拖动强度滑块后会试振一次

滑块松开并保存当前百分比后，管理器会播放一次反馈，方便直接比较强度。

:::

## 背景音乐

背景音乐由管理器播放用户选择的音频文件。

### 基本开关

- **背景音乐**：总开关。关闭后隐藏自动播放、循环、音量和播放控制。
- **选择文件**：打开系统文件选择器，选择音频文件。
- **自动播放**：音乐开启且文件可用时，管理器可在进入播放场景后自动开始。
- **循环播放**：到达文件末尾后重新开始。
- **音量**：管理器内音乐音量，范围 `0%–100%`。

### 播放控制

选择文件并且音乐开启后，会出现：

- **播放 / 暂停**：切换当前播放状态。
- **时间与进度条**：显示当前位置和总时长；拖动后跳到对应位置。
- **清除文件**：先确认，再停止播放并删除管理器保存的当前音乐选择。

::: warning 播放失败先检查文件

页面显示“无法播放”时，文件可能损坏、格式不受支持、已被删除或无法读取。重新选择一个常见格式的音频文件，不要通过反复开关音乐判断。

:::

### 推荐设置顺序

:::: steps

1. 开启背景音乐。
2. 点“选择文件”，在系统文件选择器中选择音频。
3. 确认文件出现在“选择文件”下方。
4. 按需要开启自动播放与循环。
5. 调整音量并用播放/暂停确认效果。

::::

## 触摸音效

触摸音效为界面交互播放短声音。

### 来源

:::: code-tabs

@tab 本地文件

```text
点“选择文件”，从设备中选择一段音频。
适合使用自己的提示音。
```

@tab 预置音效

```text
从管理器提供的预置音效中选择。
不需要准备本地文件，切换更直接。
```

::::

### 反馈范围

- **所有触摸**：所有使用管理器音效反馈的交互。
- **导航控件**：主要限于导航相关操作。

触摸音效开启后可以点“播放”试听当前来源。若文件已选择，也可以清除文件；预置模式不需要本地文件。

::: tip 本地音效不要过长

触摸音效用于短反馈。选择长音乐会让每次点击都从头播放，既听不清也影响操作。

:::

## 启动音效

启动音效只在管理器启动流程中播放。

可配置项：

- **启动音效开关**。
- **来源：本地文件 / 预置音效**。
- **本地文件选择**。
- **预置音效选择**。
- **播放试听**。
- **清除当前文件**。

启动音效没有“反馈范围”，因为它不是由触摸位置触发。

::: warning 启动音效受系统启动状态限制

管理器被系统直接恢复、进程仍在后台或启动页没有完整重走时，启动音效不一定再次播放。不要把它当作开机提示音；它只属于管理器启动反馈。

:::

## 音频文件管理

:::: field-group

::: field 选择文件
@type `本地`
打开系统文件选择器。只有导入成功后，文件才会成为当前选择。
:::

::: field 导入失败
@type `错误`
文件不可读、格式不支持或复制失败时，管理器保留原选择并提示无法导入。
:::

::: field 清除文件
@type `确认操作`
删除管理器保存的当前媒体选择。部分清除操作会同时停止正在播放的音频。
:::

::: field 预置音效
@type `无需文件`
直接使用管理器内置音效；切换预置不会在设备上生成自定义音频文件。
:::

::::

## 排查反馈问题

:::: collapse accordion

- **振动开了但没有感觉**

  检查系统是否关闭触感反馈、设备是否处于静音或省电模式，并尝试把强度调高。不同应用的触感实现也可能不同。

- **背景音乐没有自动播放**

  先确认音乐总开关、文件和自动播放都已开启。手动点“播放”可以区分是文件问题还是自动播放条件问题。

- **音效播放没有声音**

  检查媒体音量、勿扰模式和当前音频输出设备。触摸音效与背景音乐使用各自的选择和开关。

- **清除文件后开关还开着**

  文件清除与功能开关是两件事。需要彻底停用时关闭对应总开关。

- **多媒体设置会影响系统声音吗**

  不会替换系统铃声、通知音或系统字体。它只管理 FinaSU 管理器自己的反馈。
