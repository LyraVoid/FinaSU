# 主题商店

<Badge text="在线主题索引" type="tip" /> <Badge text="下载后才能导入" type="warning" />

主题商店浏览、下载并应用 `.fpt` 主题。可以按名称、作者和说明搜索，并按作者、官方/第三方来源、手机或平板类型筛选。

## 内置模式

在管理器内完成下载、进度展示、暂停与恢复，然后进入同一个主题导入确认框。主题文件保存在管理器私有目录，可在“我的主题”中再次应用或删除。

## 兼容模式

将主题下载链接交给系统浏览器。保存后从文件管理器用 FinaSU 打开 `.fpt`，或从“设置 → 外观 → 壁纸 → 导入主题包”选择文件。此模式适合内置下载或文件导入流程不稳定的设备。

## 应用主题

下载完成不等于已应用。选择主题并确认应用后，管理器才会执行资源、设置和语言的事务导入。主题可能包含壁纸、字体、布局、导航图标、音乐和其他外观设置，应用前查看来源与预览。

应用失败时检查文件完整性、主题所需资源和导入警告。商店模式在“设置 → 外观 → 主题商店模式”中修改，不会自动应用已经下载的主题。

完整流程见[主题预览与使用](/theme/theme-use/)。
