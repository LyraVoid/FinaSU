# 主题商店

主题商店浏览、下载并应用 `.fpt` 主题。可以按作者、来源、手机或平板类型筛选。

## 内置模式

在管理器内完成下载、进度展示、暂停与恢复，然后导入主题。

## 兼容模式

将主题文件交给系统浏览器下载。保存后打开 `.fpt` 文件即可导入。此模式适合内置下载、WebView 或文件导入失败的设备。

## 应用主题

下载完成不等于已应用。选择主题并确认应用后，管理器才会写入主题资源。主题可能包含壁纸、字体、布局、导航图标和其他外观设置，应用前查看来源与预览。

应用失败时检查文件完整性、主题所需资源和存储权限。主题商店模式可以在同一页面随时切换。
