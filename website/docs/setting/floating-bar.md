# 悬浮导航栏

悬浮导航栏把底部入口收纳到浮动胶囊中。只有导航模式选择“悬浮底部导航栏”时，这些选项才会显示。

## 样式

- **标准**：固定宽度的悬浮胶囊。
- **抽屉**：更紧凑的可展开样式。
- **紧凑圆角**：减小胶囊尺寸与圆角间距。

## 毛玻璃

Android 13 及以上可以启用实时模糊。可调项目包括：

- 模糊强度
- 背景透明度
- 高光强度
- 镜面反射
- 内发光
- 玻璃边框

旧系统不支持实时模糊时，应关闭毛玻璃并使用普通背景。

## 自动隐藏

- **自动隐藏**：无操作 3 秒后隐藏。
- **滑动隐藏**：向下滑动隐藏，向上滑动恢复。

隐藏只是界面行为，不影响页面状态或后台任务。
