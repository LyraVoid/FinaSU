# 壁纸

壁纸页面为管理器设置全局或按页面区分的背景，并控制壁纸与表面之间的层次。

## 背景

- **启用壁纸**：在界面底层显示图片。
- **多页面背景**：分别为首页、插件、超级用户、模块和设置选择图片。
- 单页可以选择、更换或移除图片。

### 视频背景

开启视频背景后，视频会替代静态壁纸。可以选择或清除视频文件，并调整视频音量。

视频模式下仍可设置遮罩；“表面不透明度”“模糊”和“从壁纸取色”只针对静态图片，会暂时隐藏。视频会持续解码播放，低性能设备可能更耗电。

## 显示

- **表面不透明度**：卡片与页面表面遮挡背景的程度。
- **模糊**：设置背景图片的模糊半径。
- **遮罩**：压暗背景以保证文字对比度。
- **日夜遮罩分离**：为浅色与深色模式分别设置遮罩。
- **卡片背景 / 聚焦卡片背景**：让特定卡片使用壁纸层。
- **从壁纸取色**：使用当前背景生成强调色。

## 工作卡片

支持专属 surface 的布局可以单独选择图片：Grid 工作卡有完整不透明度、暗度、日夜不透明度与三个隐藏开关；Focus 四张卡共享父级数值；Dashboard Hero 有独立图片与日夜表面参数；CircleUI 没有独立工作卡图片。

## 主题包

“导出主题包”保存可移植的 `.fpt` 文件；“导入主题包”应用其中的背景、surface、字体、布局、颜色、导航图标、音乐、音效与语言等受支持内容。

“恢复默认主题”会清除主题资源与主题相关偏好，包括壁纸、分页背景、视频、标题图、surface 图片、字体、导航图标、音乐、音效、布局、Stats 顶部布局、状态标签隐藏、颜色设置和主题语言。它不会删除 Root 授权、App Profile、模块或振动设置。

主题包的完整结构见 [主题包结构](/developer/theme-package/)。

想浏览和下载项目提供的壁纸，见 [壁纸图鉴](/setting/wallpaper-gallery/)。
