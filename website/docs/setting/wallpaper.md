# 壁纸

壁纸页面为管理器设置全局或按页面区分的背景，并控制壁纸与表面之间的层次。

## 背景

- **启用壁纸**：在界面底层显示图片。
- **多页面背景**：分别为首页、插件、超级用户、模块和设置选择图片。
- 单页可以选择、更换或移除图片。

### 视频背景

开启视频背景后，视频会替代静态壁纸。可以选择或清除视频文件，并调整视频音量。

视频模式下仍可设置遮罩；“表面不透明度”“模糊”和“从壁纸取色”只针对静态图片，会暂时隐藏。视频会持续解码播放，低性能设备可能更耗电。

## 显示

- **表面不透明度**：卡片与页面表面遮挡背景的程度。
- **模糊**：设置背景图片的模糊半径。
- **遮罩**：压暗背景以保证文字对比度。
- **日夜遮罩分离**：为浅色与深色模式分别设置遮罩。
- **卡片背景 / 聚焦卡片背景**：让特定卡片使用壁纸层。
- **从壁纸取色**：使用当前背景生成强调色。

## 工作卡片

工作卡片可以单独选择图片，并控制不透明度、背景暗度、日夜不透明度以及状态图标、标题和模式标签的显隐。

## 主题包

“导出主题包”保存可移植的 `.fpt` 文件；“导入主题包”应用其中的背景和相关资源；“恢复默认主题”会清除壁纸、字体、首页布局与导航图标。

主题包的完整结构见 [主题包结构](/developer/theme-package/)。

想浏览和下载项目提供的壁纸，见 [壁纸图鉴](/setting/wallpaper-gallery/)。
