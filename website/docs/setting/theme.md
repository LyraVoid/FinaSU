# 主题与颜色

“主题设置”集中管理明暗模式、动态配色和 Material 3 Expressive 视觉参数。

## 明暗模式

- 跟随系统：使用设备的深浅色状态。
- 浅色：固定浅色界面。
- 深色：固定深色界面。
- AMOLED 纯黑：深色模式下使用纯黑背景。

## 动态配色

启用 Monet 后，强调色来自系统动态颜色。关闭后可从红、粉、紫、深紫、靛蓝、蓝、青、蓝绿、绿、黄、琥珀、橙、棕、蓝灰和樱雪等强调色中选择。

壁纸页面还可以启用“从壁纸取色”，让当前页面的配色由壁纸生成。

## 色彩规范

- **色彩标准**：MD3 2021 或 M3E 2025。
- **色彩风格**：按所选标准生成不同色相关系。
- **界面风格**：选择当前 M3E 组件呈现方式。
- **按钮指示器**：在开关中加入状态图标。
- **离散滑块**：在滑块轨道显示刻度。

主题包导入导出与在线主题见 [主题商店](/setting/theme-store/)。
