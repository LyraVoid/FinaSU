# 模块卡片与横幅

## 卡片

- **显示模块详情**：在模块卡片上显示版本、作者与描述。
- **折叠模块卡片**：在卡片展开前收起操作按钮。
- **拼接卡片**：把同一分组内的卡片连成一段。
- **按钮样式**：选择卡片操作按钮的呈现方式。
- **描述最大行数**：超过行数的介绍自动折叠，点击卡片展开。

分组排序会区分元模块、Zygisk、LSPosed、带 WebUI 和带操作的模块。

## 横幅

模块卡片可以显示横幅：

- **自定义横幅**：开启后可长按模块卡片，为该模块选择本地横幅图片。
- **API 模式**：从 API 或本地目录获取横幅。
- **横幅 API 来源**：填写 API 链接或本地目录。
- **市场来源**：从模块市场元数据读取横幅。

“清除横幅缓存”会删除已下载的横幅缓存，下一次显示时重新获取。自定义不透明度开启后，滑块可覆盖跟随壁纸的默认透明度。远程图片可能包含第三方跟踪内容，启用前确认来源。
