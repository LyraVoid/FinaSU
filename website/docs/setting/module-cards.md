# 模块卡片与横幅

## 卡片

- **显示更多信息**：在模块卡片中展开附加元数据。
- **折叠系统模块**：把系统相关模块收进折叠组。
- **拼接卡片**：把同一分组内的卡片连成一段。
- **按钮样式**：选择卡片操作按钮的呈现方式。
- **描述最大行数**：超过行数的介绍自动折叠，点击卡片展开。

分组排序会区分元模块、Zygisk、LSPosed、带 WebUI 和带操作的模块。

## 横幅

模块卡片可以显示横幅：

- **Folk 来源**：使用仓库提供的横幅。
- **API 模式**：从配置的横幅 API 获取。
- **横幅 API 地址**：填写 HTTP(S) 服务地址。
- **市场来源**：从模块市场元数据读取横幅。

“清除缓存”会删除已下载的横幅缓存，下一次显示时重新获取。横幅不透明度可以统一调整，也可以启用自定义不透明度。远程图片可能包含第三方跟踪内容，启用前确认来源。
