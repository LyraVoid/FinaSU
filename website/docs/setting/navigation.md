# 导航

## 导航模式

- **自动传统导航栏**：按屏幕尺寸在底部导航和侧边导航之间切换。
- **始终底部导航栏**：适合手机。
- **始终侧边导航栏**：适合平板或横屏。
- **悬浮底部导航栏**：使用独立胶囊样式，详见 [悬浮导航栏](/setting/floating-bar/)。

## 页面与角标

可以隐藏插件、超级用户和模块入口，也可以显示已授权应用与已启用模块数量角标。隐藏入口不会删除数据。

## 手势与图标

- **预测性返回手势**：请求系统提供预测性返回动画。
- **自定义底部导航图标**：为各入口选择本地图片。
- **布局变体**：为插件、超级用户和模块页面选择传统或 M3E 顶栏。

导航布局改动可能要求重新进入页面才完全生效。壁纸恢复默认时会一并清除自定义导航图标。
