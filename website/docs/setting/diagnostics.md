# 诊断与反馈

## SU 日志

打开 KernelSU 系 SU 日志，记录 Root 执行、传统 SU、授权和守护进程事件。内核不支持或策略强制开启时，设置不可用或不可修改。详见 [SU 日志](/manager/su-log/)。

## 发送日志

设置首页的“发送日志”会收集管理器日志，用于问题反馈。日志可能包含包名、UID、路径、内核版本和设备状态；提交前检查敏感信息。

## 问题反馈

反馈入口打开项目的问题页面。提交前先确认：

- 管理器版本、内核版本和运行模式。
- 设备型号、Android 版本与完整 KMI。
- 安装方式与最近改动的模块、主题或引擎。
- 可重复的操作步骤、预期结果和实际结果。
- 相关日志，以及失败发生前后做过的救援操作。

不要在公开问题中粘贴管理器密码、WebDAV 凭据或私钥。
