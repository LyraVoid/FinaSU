# 身份验证

身份验证用于在管理器中执行敏感操作前确认设备持有人。它独立于 Root 授权和系统锁屏。

## 默认方式

可以选择无、强生物识别、数字密码或图案。未设置凭据时不能选择依赖它的方式。生物识别不可用或暂时锁定时，可以按配置回退到 PIN 或图案。

## PIN 与图案

- PIN 为 4 位或 6 位数字。
- 图案至少连接 4 个点。
- 修改或清除凭据需要先验证旧凭据。

凭据只保存单向校验信息。验证失败会有重试间隔，存储读取失败时页面会禁止修改，避免覆盖现有数据。

## 保护目标

可以分别保护：

- 应用启动
- 模块安装
- 模块卸载
- 模块禁用
- 分区刷写
- 主题或 `.fpt` 导入
- 重启操作

默认方式用于所有已启用目标。保护应用启动后，每次重新进入管理器都可能要求验证。
