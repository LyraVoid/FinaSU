# 维护与危险操作

## 免责声明

设置首页的免责声明说明 Root、刷写、第三方模块和安全策略变更的风险。继续操作表示接受设备数据、保修与认证状态可能变化。

## 卸载

“卸载”只在修补镜像与驱动状态允许时显示，提供：

- **临时卸载**：下次重启恢复到未加载状态，之后 Root 可能恢复。
- **永久卸载**：移除 Root 与模块管理数据。
- **恢复原厂镜像**：存在匹配备份时刷回原厂启动分区，通常用于 OTA 前。

恢复原厂镜像不等于永久卸载；永久卸载也可能因设备状态要求之后重新刷写。

## 操作前

1. 备份启动分区、模块和超级用户列表。
2. 确认系统版本与槽位。
3. 保留可用的 `fastboot` 或 Recovery 环境。
4. 阅读当前构建的确认对话框，不根据其他衍生项目的行为推断。

无法启动时使用 [救砖](/guide/rescue-bootloop/)。
