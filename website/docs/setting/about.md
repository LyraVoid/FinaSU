# 关于

关于页面显示管理器 `versionName`、项目入口和许可证信息。

## 版本

- **管理器版本**：当前 APK 的版本名称。
- **内核完整版本**：驱动源码标签、提交和分支。
- **运行模式**：修补启动镜像、运行时模块、内核内置或越狱模式。

版本号和运行模式是不同字段。反馈问题时应分别提供。
