# 关于

<Badge text="首页快捷入口" type="info" /> <Badge text="反馈时先看这里" type="tip" />

设置首页的“关于”页面只显示管理器名、管理器版本和项目入口。它不是一个完整的运行状态面板。

## 页面内容

- **应用名**：当前管理器使用的名称。
- **管理器版本**：当前 APK 的 `versionName`。
- **GitHub**：打开项目源码与发布页面。
- **Telegram**：打开项目频道。

::: info 关于页不显示驱动版本

内核构建、运行方式、UAPI 和驱动状态应在首页状态卡或其他诊断入口查看。反馈问题时，不能只提供“关于”页里的管理器版本。

:::

## 反馈时还需要什么

建议同时记录：

- 首页显示的实际运行方式：LKM、Built-In 或 Jailbreak mode。
- 内核构建版本、UAPI 与 KMI。
- 设备型号、Android 版本和安全补丁级别。
- 可重复步骤、预期结果与实际结果。
- “发送日志”导出的日志文件。

详细清单见 [诊断与反馈](/setting/diagnostics/)。
