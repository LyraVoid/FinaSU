# 字体

字体页面提供三种模式：

- **软件默认**：使用管理器随包字体。
- **系统默认**：跟随设备的系统字体。
- **自定义**：选择一个字体文件并应用到管理器。

选择不支持的字形或损坏的字体会导致文字缺字或无法加载。应用失败时恢复默认字体。

字体文件只影响管理器界面，不会替换系统字体，也不会自动进入主题包。需要随 `.fpt` 分发时，应通过主题导出流程生成完整包。
