# 字体

<Badge text="只改管理器" type="tip" /> <Badge text="失败可恢复" type="warning" />

字体设置只改变 FinaSU 管理器界面的文字，不替换 Android 系统字体，也不改变模块、Root 授权或其他应用。

## 三种字体模式

::: table 字体模式

| 模式 | 使用什么字体 | 适合 |
| --- | --- | --- |
| **软件默认** | 使用 FinaSU 随包字体 | 想要管理器自己的统一外观 |
| **系统默认** | 跟随设备当前系统字体 | 希望与其他应用保持一致 |
| **自定义** | 使用用户导入的字体文件 | 明确知道自己要使用哪种字体 |

:::

切换模式后，管理器界面会重新应用字体。

## 使用自定义字体

:::: steps

1. 进入“设置 → 外观 → 字体”。
2. 选择“自定义”。
3. 点“选择字体文件”。
4. 从系统文件选择器中选择字体文件。
5. 返回首页和其他页面，检查文字是否完整显示。

::::

导入成功后，字体文件会复制到管理器私有目录；之后删除原始文件，不会影响已经导入的字体。

::: warning 字体格式和字符覆盖

损坏、格式不受支持或缺少常用汉字的字体会导致文字缺字、方块字或直接应用失败。出现问题时点“恢复默认字体”，不要继续叠加其他字体文件。

:::

## 恢复默认字体

自定义模式下，选择过字体文件后会出现“恢复默认字体”：

- 点击后先显示确认对话框。
- 确认会删除管理器保存的自定义字体文件。
- 恢复目标是 **软件默认**，不是“系统默认”。
- 如果只想跟随系统字体，恢复后再手动选择“系统默认”。

## 与主题包的关系

字体是管理器外观的一部分，但不会自动替换系统字体。主题包需要包含字体资源时，应使用完整的 `.fpt` 导出流程。

## 常见问题

:::: collapse accordion

- **为什么选择自定义后看起来像系统字体？**

  当前没有可用的自定义字体文件时，管理器会退回可用的默认字体。重新选择字体文件。

- **为什么部分汉字变成方块？**

  字体文件缺少对应字形。换用字形覆盖完整的字体。

- **恢复默认会删除系统字体吗？**

  不会。只会删除管理器私有目录中的自定义字体并切回软件默认。
