# 外观

<Badge text="设置入口 2/8" type="info" /> <Badge text="只改界面" type="tip" />

“外观”决定管理器看起来是什么样：颜色、背景、字体、首页结构、图标和信息卡片。这里绝大多数改动不会改变 Root 授权、模块状态或内核功能，但“恢复默认主题”会清除多项自定义资源。

::: tip 进入方式

打开管理器 → 设置 → 点第一行第二个 **外观**。

:::

## 外观功能地图

::: table 从需求找选项

| 想改什么 | 选项 |
| --- | --- |
| 明暗、强调色、Material 风格 | 主题设置 |
| 背景图、视频、透明度、模糊 | 壁纸 |
| 界面字体 | 字体 |
| 在线下载或导入 `.fpt` | 主题商店 |
| 桌面上的管理器图标 | 启动器图标 |
| 首页是圆形、网格、仪表盘还是统计页 | 首页布局 |
| 顶栏是大标题还是传统样式 | 布局变体 |
| 首页底部推荐/自定义卡片 | 首页底部卡片 |
| 首页标题文字或标题图片 | 顶栏标题与高级标题图片 |
| 首页隐藏指纹、Zygisk、SUSFS、挂载信息 | 首页信息 |
| 整体字号密度、模块介绍折叠行数 | 界面缩放、模块描述最大行数 |

:::

## 主题设置

“主题设置”控制管理器的明暗模式、强调色和 Material 3 组件表现。

### 明暗模式

- **跟随系统**：系统切换深浅色时，管理器一起切换。
- **浅色**：固定使用浅色界面。
- **深色**：固定使用深色界面。
- **AMOLED 纯黑**：在深色模式中使用纯黑或近黑背景，适合 OLED 屏幕，也更省电。

### 动态配色与强调色

启用系统的动态配色后，强调色会参考设备当前壁纸或系统主题。关闭动态配色后，可以从管理器提供的强调色中选择，例如红、粉、紫、蓝、青、绿、黄、橙、棕等。

“从壁纸取色”是壁纸页的独立选项。它会让界面颜色从管理器自己的壁纸生成，不等同于系统动态配色。

### 色彩标准与风格

- **色彩标准**：决定按 MD3 2021 还是 M3E 2025 的色彩规则生成配色。
- **色彩风格**：在柔和、中性、活力、表现、彩虹、缤纷、单色、忠实和内容等色相关系中选择。
- **按钮指示器**：在开关中加入状态图标。
- **离散滑块**：在滑块轨道上显示刻度。

这些参数相互组合。更换色彩标准或色彩风格后，原来的强调色看起来发生变化是正常的。

主题细节见 [主题与颜色](/setting/theme/)。

## 壁纸

壁纸页把背景和界面表面分层处理：

- **启用壁纸**：在页面底层显示背景。
- **统一或分页背景**：可以让所有页面共用一张图，也可以为首页、插件、超级用户、模块和设置分别选图。
- **视频背景**：用循环播放的视频替代静态壁纸，并可调整视频音量。
- **表面不透明度**：控制卡片遮挡背景的程度。越低越透，文字对比度也越难保证。
- **模糊**：柔化背景，减少复杂图片对文字的干扰。
- **遮罩**：压暗背景，提升可读性。
- **日夜遮罩分离**：分别为浅色与深色模式设置遮罩强度。
- **卡片背景 / 聚焦卡片背景**：让特定卡片使用壁纸层。
- **从壁纸取色**：从图片提取管理器强调色。多背景模式使用首页图片作为全局种子，页面滑动不会实时重算；视频模式不提供实时取色。

### 工作卡片

支持该 surface 的布局可以单独设置工作卡背景：Grid 工作卡可控制图片、不透明度、暗度、日夜不透明度和三个隐藏开关；Focus 四卡共享父级透明度/暗度；Dashboard 使用 Hero 图片。CircleUI 没有独立工作卡图片。部分布局可以长按卡片直接编辑。

### 视频背景

开启视频背景后，视频会替代静态图片：

- 选择视频文件。
- 调整视频音量。
- 清除当前视频文件。

视频模式下仍可使用遮罩，但“表面不透明度”“模糊”和“从壁纸取色”会隐藏，因为它们针对静态图片。视频解码与持续播放会增加耗电，低性能设备应谨慎使用。

### 壁纸图鉴

设置首页的“壁纸图鉴”用于浏览和预览壁纸，可按手机、平板或融合设备筛选，并切换瀑布流或堆叠展示。

点“下载”只会保存图片：Android 10 及以上写入 `Pictures/FinaSU`，Android 9 及以下写入管理器专属外部图片目录。下载==不会自动变成管理器壁纸==；需要使用图片时，回到“外观 → 壁纸”，通过“选择图片”从系统文件选择器中选中它。

完整说明见 [壁纸图鉴](/setting/wallpaper-gallery/)。

完整说明见 [壁纸](/setting/wallpaper/)。

## 字体

字体页有三种模式：

- **软件默认**：使用管理器随包字体。
- **系统默认**：跟随设备的系统字体。
- **自定义**：从设备选择一个字体文件。

自定义字体只影响管理器界面，不替换 Android 系统字体，也不自动进入 `.fpt` 主题包。字体缺字、损坏或格式不兼容时，恢复默认字体。

“恢复默认字体”会删除导入文件并切回**软件默认**；需要跟随系统字体时，恢复后再手动选择“系统默认”。

详见 [字体](/setting/font/)。

## 主题商店

主题商店用于浏览、下载和应用 `.fpt` 主题。主题可能包含壁纸、字体、颜色、布局、导航图标、音效等资源。

::: warning 下载成功不等于已经应用

下载只把文件带到设备。仍要在主题商店或壁纸页确认导入和应用；应用前检查作者、预览与来源。

:::

### 主题商店模式

:::: code-tabs

@tab 内置模式

```text
由管理器在应用内下载、显示进度并导入。
适合管理器内下载和文件处理正常工作的设备。
```

@tab 兼容模式

```text
把下载交给系统浏览器。
适合 WebView、内置下载或文件选择器出现问题的设备。
下载后打开 .fpt 文件完成导入。
```

::::

两种模式可以在外观页随时切换，不会自动应用已下载主题。

详见 [主题商店](/setting/theme-store/)。

## 启动器图标

启动器图标决定桌面上 FinaSU 使用哪种图标样式，例如默认、几何或 KernelSU 风格。它只改变启动器展示，不改变包名、签名、授权或运行模式。

## 首页布局

当前提供五种首页布局：

::: table 首页布局

| 布局 | 主要特点 | 适合 |
| --- | --- | --- |
| **CircleUI** | 圆形工作卡与侧重状态的首页 | 喜欢集中查看 Root 状态的用户 |
| **GridUI** | 双列卡片 | 希望在首页看到更多入口 |
| **FocusUI** | 聚焦主要状态，并随屏幕方向调整 | 手机与平板混用 |
| **DashboardUI** | 仪表盘式信息卡 | 喜欢分区信息面板 |
| **StatsUI** | 以超级用户、模块与实时指标为中心 | 需要一眼查看统计 |

:::

切换布局只改变首页排列，不修改主题颜色、Root 状态或模块数据。各布局的详细结构见“主题”栏目的对应页面。

## 布局变体

布局变体作用于插件、超级用户和模块页面：

- **M3E**：大标题、可折叠内嵌搜索栏与更明显的滚动层次。
- **传统**：紧凑顶栏，占用更少垂直空间。

如果页面内容被大标题遮挡，或平板横屏希望显示更多条目，可以切换到“传统”。

## 首页底部卡片

首页最下方可以放一张快捷卡片。它在首页内容之后显示，不参与 Root 或模块状态判断。

::: table 四种显示方式

| 选项 | 卡片内容 | 点击行为 |
| --- | --- | --- |
| **了解 FinaSU** | 一行“了解 FinaSU / 了解 FinaSU 的功能与模块” | 打开 FinaSU 官网 |
| **支持开发与 KernelSU** | 两行：支持开发、了解 KernelSU | 分别打开捐赠页和 KernelSU 指南 |
| **隐藏** | 不显示卡片 | 无 |
| **自定义** | 自己填写的标题、副标题和链接 | 打开填写的 HTTP(S) 链接 |

:::

“了解 FinaSU”是默认选项。切到“隐藏”或暂时留空自定义内容，只影响首页展示，不会删除已经填写的自定义文字。

### 自定义卡片

只有选择“自定义”后，才会出现以下三项：

:::: field-group

::: field 卡片标题
@type `自定义`
@default `粗体标题`
显示在卡片第一行，是视觉重点。
:::

::: field 卡片副标题
@type `自定义`
@default `说明文字`
显示在标题下方，用来说明卡片用途。
:::

::: field 链接地址
@type `HTTP(S)`
@default `必填`
点击整张卡片时打开。只接受 `http://` 或 `https://` 地址。
:::

::::

::: warning 三项都填写后卡片才会出现

标题、副标题和链接必须全部非空。任何一项留空时，自定义模式不会显示半成品卡片，效果等同于“隐藏”。无效链接不会保存，编辑框会保留并提示重新输入。

:::

填写时按“文字是给谁看的、点进去要做什么”来写。例如：

```text
标题：模块使用说明
副标题：查看当前模块的安装与排错步骤
链接：https://example.com/module-guide
```

`example.com`、`ftp://example.com` 和空白内容都不符合要求，必须带完整的 `http://` 或 `https://`。

## 顶栏标题与标题图片

顶栏标题有三种来源：

- **应用名**：使用当前应用名称。
- **KernelSU**：显示 KernelSU 标题。
- **自定义**：输入自己的标题文字。

如果启用**高级标题图片**，图片会替代文字标题。启用后可以调整：

- 日间不透明度。
- 夜间不透明度。
- 暗化程度。
- 水平偏移，范围为 `-200 dp` 到 `200 dp`。

文字标题仍会保留在配置中。关闭标题图片后，会重新显示所选文字标题。

## 首页信息

首页信息区可以隐藏以下行：

- **系统指纹**：通常包含设备、系统构建和内核标识。
- **Zygisk 实现**：仅在当前确实存在 Zygisk 实现时显示对应开关。
- **SUSFS**：仅在检测到 SUSFS 时显示。
- **模块挂载**：仅在 Folk Mount 状态可读时显示。

::: info 隐藏不是关闭

隐藏只改变首页展示，不会关闭 Zygisk、SUSFS 或模块挂载，也不会改变检测结果。排查兼容问题时，应先恢复显示再判断实际状态。

:::

## 显示密度

### 界面缩放

界面缩放范围为 `80%–110%`。它调整管理器整体显示比例：

- 调大后文字和控件更易读，但一屏可见内容更少。
- 调小后可以显示更多内容，但过小会影响点击和阅读。
- 缩放不会改变 Android 系统显示大小。

### 模块描述最大行数

范围为 `1–5 行`。模块介绍超过该行数时会折叠，点击模块卡片可展开全文。

如果模块作者把重要安装说明写得很长，不建议设为 1 行，否则容易漏看警告。

## 外观操作顺序

::: timeline 一次完整的外观调整

- 选择明暗模式、动态配色或强调色，确定整体色彩
  time=基础

- 设置壁纸、模糊、遮罩和表面不透明度，确保文字仍然清楚
  time=背景

- 选择首页布局、布局变体和首页底部卡片
  time=结构

- 设置字体、启动器图标、标题图片、信息显隐、缩放和描述行数
  time=细节

- 需要迁移或分享时，从壁纸页导出 `.fpt`；否则留在当前设备即可
  time=保存 type=success

:::

::: warning 恢复默认会清除多项内容

“恢复默认主题”不只是删除当前壁纸，还可能清除字体、首页布局和自定义导航图标。执行前确认是否需要先导出主题包。

:::
