# 管理器总览

FinaSU 管理器是内核驱动与用户态服务的控制面。首页展示当前 Root、内核、Zygisk、SUSFS 与挂载状态，并提供安装、重启和救援入口。

## 主要区域

- **首页**：运行状态、版本、模块数量和常用快捷操作。
- **超级用户**：白名单、授权记录、App Profile 与 SU 日志。
- **模块**：模块安装、启停、更新、WebUI、Lua 插件和内核模块。
- **模块仓库**：从内置或自定义来源浏览并安装模块。
- **设置**：外观、行为、安全、备份、内置引擎和危险操作。
- **关于**：管理器版本、内核版本、项目链接和许可证。

## 状态优先级

如果首页显示驱动不可用，先检查管理器签名、内核驱动版本与当前运行模式。安装模块或修改内置引擎之前，应先解决驱动连接问题。

## 权限

管理器不需要常驻 Root Shell 才能完成大多数管理操作，但安装模块、备份分区、管理内核模块和插件时仍需要有效的 Root 通道。
