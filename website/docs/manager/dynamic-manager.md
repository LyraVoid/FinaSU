# 动态管理器

内核默认只信任构建时写入的管理器签名。动态管理器允许在设备上持久化额外签名，使另一个构建能够管理驱动。

## 使用

在应用的 App Profile 页面找到“设为动态管理器”。管理器会提取 APK 证书大小与 SHA-256，并请求内核加载该签名；随后还需要给这个 UID 授予动态管理器权限。

## 预设与实验选项

默认只对预设管理器签名显示开关。“允许任意应用作为动态管理器”是实验选项，会扩大受信任范围。

## 风险

动态管理器拥有管理内核 Root 的能力。签名或包名相同不保证应用可信；只对自己构建并校验过的 APK 使用此功能。

升级或重新签名会改变证书。旧授权不会自动跟随新构建，必须重新设置。
