# Folk Mount

Folk Mount 是 FinaSU 的模块注入引擎，负责在启动时选择模块提供者并发布文件。

## 模式

| 模式 | 下次启动的行为 |
| --- | --- |
| 自动 | 有活动元模块时交给元模块，否则使用内置引擎 |
| 内置 | 始终使用 Folk Mount 内置执行器 |
| 仅元模块 | 交给活动元模块；没有可用脚本时不注入 |
| 内置（VFS） | 使用 NoMount 驱动，驱动失败时回退 |
| 关闭挂载 | 不注入模块，模块保持失效直到重新选择 |

模式改动只影响下一次启动，不会立即挂载或卸载。

## 内置执行器

内置执行器把模块文件发布到目标路径，并复制必要的元数据与 SELinux 上下文。执行过程使用事务记录；发布失败时会尝试回滚，无法撤销的挂载会作为残留报告。

## 元模块

活动元模块可以接管安装脚本 `metainstall.sh`、卸载脚本 `metauninstall.sh` 与挂载脚本 `metamount.sh`。元模块被禁用或移除后，自动模式会回到内置引擎。

## 状态

挂载状态会记录本次启动使用的提供者、目标数量、跳过数量、警告和错误。模块没有生效时，先检查模式与状态，再检查模块脚本。

## 选择建议

普通使用保持“自动”。只有在明确需要 Magisk 风格挂载、特定元模块或 VFS 注入时才手动固定提供者。
