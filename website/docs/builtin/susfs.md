# SUSFS

<Badge text="需要内核支持" type="warning" /> <Badge text="进阶" type="danger" />

==SUSFS 是一组在内核层隐藏路径、挂载和文件元数据等痕迹的能力==。FinaSU 不包含 SUSFS 实现，只负责检测、配置和调用已经存在的 SUSFS 接口。

::: important SUSFS-LKM 与 FinaSU 的 LKM 安装方式不是一回事

FinaSU 本身可以通过 LKM 方式安装，这不代表设备自动拥有 SUSFS。SUSFS 仍需要单独的源码集成版本或 SUSFS-LKM。

:::

## 内核源码集成

完整方案需要修改目标设备的内核源码：

1. 获取与设备 Linux 版本匹配的内核源码。
2. 应用对应版本的 SUSFS 补丁。
3. 启用 `CONFIG_KSU_SUSFS` 及相关子选项。
4. 重新编译内核并刷写完整的 `boot` 镜像。

当前集成通常还要求 FinaSU 以 `CONFIG_KSU=y` 一起编入内核，因为补丁会引用驱动符号。具体配置见 [内核集成](/developer/builtin-integration/#susfs)。

源码集成可以提供较完整的钩子和能力集，但构建、升级以及系统 OTA 后重新适配都更麻烦。它适合能够维护内核源码、并且明确需要完整 SUSFS 能力的用户。

## SUSFS-LKM 替代方案

SUSFS-LKM 把 SUSFS 做成可加载内核模块，不需要重新编译完整内核。它通常有两种使用方式：

- 使用内核模块加载器直接加载匹配当前内核的 `.ko`。
- 封装成 Magisk 模块，在开机脚本中选择匹配的 KMI，再由模块加载器加载。

两种方式最终都是把内核模块载入当前系统，而不是修改内核源码。必须选择与真实内核版本、KMI 和厂商 ABI 匹配的模块；自动改写 vermagic 或加载成功都不代表 ABI 一定兼容。

::: warning 不要叠加两套 SUSFS

源码集成版和 SUSFS-LKM、或两个不同来源的 SUSFS-LKM 不应同时加载。切换实现时先停用旧实现并重启；删除 `.ko` 文件不会卸载已经运行在内存中的模块。

:::

## 与源码集成版的差距

SUSFS-LKM 是替代方案，不是源码集成版的等价替代。实际能力取决于模块导出的接口，通常存在以下差距：

| 方面 | 内核源码集成 | SUSFS-LKM |
| --- | --- | --- |
| 能力范围 | 由内核补丁和编译选项决定，覆盖通常更完整 | 受模块实现、导出符号和 proc 节点限制，可能只有部分能力 |
| 启动时机 | 可在内核启动早期接入 | 通常在系统启动后的模块加载阶段接入 |
| 动态 kstat | 可以完整配合挂载前后采样 | 加载过晚时可能留到下次重启再应用 |
| 文件重定向 UID 方案 | 可使用源码版支持的完整范围 | 部分 UID 方案与源码版不等价，FinaSU 会拒绝不安全用法 |
| 更新方式 | 重新编译并刷写内核 | 替换模块后重启，但需要重新确认 KMI 兼容性 |
| 兼容风险 | 补丁与内核版本不匹配会导致构建或启动问题 | 厂商内核 ABI、符号和模块加载限制可能直接导致加载失败 |

因此，SUSFS-LKM 适合无法编译内核、但能接受功能较少和兼容性风险的用户。需要完整能力或长期稳定维护时，仍应优先考虑源码集成。

## FinaSU 中显示什么

打开 **设置 → 功能 → SUSFS** 后，FinaSU 会检测当前内核是否提供兼容的 SUSFS 控制接口，并只开放对方实际报告的能力。

```mermaid
flowchart LR
    A["内核源码集成或 SUSFS-LKM"] --> B["SUSFS 控制接口"]
    B --> C["FinaSU 检测能力"]
    C --> D["保存与应用规则"]
```

- 未检测到接口：当前没有可用的 SUSFS 实现。
- 协议未知：只读显示，不执行未经验证的控制。
- 协议兼容：按内核报告的能力开放配置。
- 保存配置不等于已经应用，修改已生效规则后通常需要重启。

FinaSU 不会替你给内核打补丁、安装 `.ko` 或加载 LKM。LKM 的加载与开机自启由你所选择的模块或加载器负责。

## 使用边界

- 不要从未知来源加载内核模块。LKM 运行在内核态，错误模块可能导致无法开机。
- 不要把“模块加载成功”当成“所有 SUSFS 功能可用”，应以 FinaSU 的能力检测和实际效果为准。
- SUSFS 不保证通过所有完整性检测，仍需结合系统属性、文件内容和行为差异判断。
- 修改前准备可恢复的启动镜像或模块禁用手段。
