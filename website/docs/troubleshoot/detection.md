# 检测与隐藏

FinaSU 提供的是分层隐藏能力，没有任何配置能保证通过全部应用检测。

## 按优先级排查

1. 在 App Profile 中为该应用启用“卸载模块”。
2. 需要隐藏挂载记录时启用内核挂载过滤或改用 NoMount。
3. 启用隐藏 SELinux 修改和 AVC 日志伪装。
4. 内核集成 SUSFS 时，再按能力启用对应项目。
5. 检查该应用是否针对硬件认证、系统属性、调试状态或行为模式检测。

## 不要全局堆叠

把所有应用都设为隐藏会增加兼容问题。先确认应用实际检测层面，再只对目标应用启用必要策略。

隐藏设置出错也可能让应用无法读取自己的模块或配置。出现功能异常时先关闭最近开启的隐藏项，并对比 [SU 日志](/manager/su-log/) 与应用自身日志。

## 能力门控

内核不支持的功能不会出现在设置中。不要通过修改配置文件强制开启；驱动和设备端版本不匹配时，请求会被拒绝或得不到预期结果。
